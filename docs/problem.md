### Problem Statement

Many software engineers document things about their project using
markdown files, often time they need to include mermaid diagrams in
these markdown documents, but tools for viewing these markdown documents
on the terminal either don't support rendering the mermaid as diagrams
and just show them as plain text, or some that supports it are a little
bit slow and actually renders it as screenshot taken from compiling the
diagram in a headless browser. Some of these tools will break when the
diagrams are quite long.
