# Requirements

## Functional Requirements
- Users should be able to read markdown document from their terminal
- Users should be able to read markdown document that contains mermaid
  diagrams
- Users should get proper feedback if the mermaid diagram has syntax
  issue and unable to render.
- Users should be able to optionally select the theme they want the
  document to render with.

## Non-Functional Requirements
- High Speed: It should have speed as a feature.
- Extensibility: Might include support for some other tools that
  markdown support.
